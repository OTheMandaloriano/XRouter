# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) (v2.1) como código de conduta.

Em resumo: seja respeitoso, acolhedor e profissional. Não são tolerados assédio,
discriminação ou comportamento abusivo em nenhum espaço do projeto (issues, PRs,
discussões).

Violações podem ser reportadas de forma privada ao mantenedor via
**GitHub Security Advisories** ou pelas configurações de moderação do repositório.
